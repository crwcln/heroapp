One-time setup for the site owner

In EdgeOne, set BORDER_TOOL_PASSWORD, GITHUB_TOKEN, and GITHUB_REPOSITORY. The GitHub token needs repository contents read/write and Actions workflow-dispatch access.

In GitHub, add an Actions repository secret named EDGEONE_DEPLOY_WEBHOOK_URL with the same deploy webhook URL as EdgeOne's DEPLOY_WEBHOOK_URL. The repository must include the boundary-build workflow, and its deployment branch must allow GitHub Actions to push generated files.

Publishing writes the catalog and any loaded overrides/manual GeoJSON to the configured deployment branch, then builds and deploys the generated map data.
